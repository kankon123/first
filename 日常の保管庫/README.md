# 日常の保管庫

思い出すためのメモ置き場。

## 使い方

1. 適当に投げてOK（店名・人名・リンク・一言メモで十分）
2. こちらで分類・整理して格納する
3. あとから探すときは [`INDEX.md`](./INDEX.md) を見る

## フォルダ

| 場所 | 入れるもの |
|------|------------|
| `おすすめ/グルメ/` | 行きたい店・食べたいもの |
| `おすすめ/場所/` | 行きたい場所・スポット |
| `人からの話/` | 誰かから聞いた話・紹介 |
| `仕事/指導メモ/` | 先生・現場からの指導・今後の注意 |
| `仕事/薬局・施設/` | 開局時間・駐車・連絡先など現場の基礎情報 |
| `inbox/` | まだ整理していない生メモ |

## メモの書き方（目安）

- **誰から** / **いつ** / **何** / **どこ** / **リンク**
- 分からない項目は空欄のままでOK
