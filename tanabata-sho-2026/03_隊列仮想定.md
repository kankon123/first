# 隊列仮想定（枠順発表前）

※枠順で大きく動く。これは「脚質ベースの仮隊列」。  
※括弧内は想定人気帯。

## 仮隊列（スタート〜1角イメージ）

```
【逃げ】
  ショウナンマグマ（大穴）
  ※バトルボーン／アスクナイスショーがハナを主張する可能性あり

【番手〜先行2〜4番手】
  バトルボーン（3人気想定）
  アスクナイスショー（5人気想定）
  サヴォーナ（1人気想定）
  オーロラエックス（穴〜中穴）
  センツブラッド（中穴）

【好位〜中団】
  ヤマニンブークリエ（4人気想定）
  カラマティアノス（2人気想定）
  クリスマスパレード（穴）※本来先行だが近走後方気味
  コントラポスト（穴）

【中団〜後方】
  オールナット（中穴〜）
  マイネルモーント（中穴）
  リカンカブール（穴）

【後方】
  メリオーレム（穴）
  ボーンディスウェイ（穴）
  オニャンコポン（大穴）
```

## 4角通過イメージ（仮説A: 平均〜やや前傾）

| 通過帯 | 想定馬 |
|--------|--------|
| 1〜3番手 | ショウナンマグマ／バトルボーン／アスクナイスショー or サヴォーナ |
| 4〜6番手 | サヴォーナ／センツブラッド／オーロラエックス／ヤマニンブークリエ |
| 7〜10番手 | カラマティアノス／クリスマスパレード／コントラポスト／オールナット |
| 11番手以降 | マイネルモーント／メリオーレム／リカンカブール／ボーン／オニャンコポン |

## 展開のカギになる馬（台本で強調）

1. **ショウナンマグマ** … 逃げるか／絡まれるかで全体ペースが決まる  
2. **バトルボーン** … 戸崎がハナを取るか番手で我慢するか  
3. **アスクナイスショー** … 田辺が積極策に出るか  
4. **サヴォーナ** … 好位確保できるか（福島適性の本命側）  
5. **カラマティアノス** … 中団からスムーズに進出できるか（スロー向き指摘との相性）
