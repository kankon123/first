# コース傾向と展開仮説（枠順前）

## 福島芝2000mの要点（台本用ワンフレーズ）

- スタートは4コーナーポケット。最初の直線が約500mと長い  
- 最後の直線は約292mと短い → **直線一気は届きにくい**  
- アップダウンあり。テン速＋スタミナ＋小回り機動力が問われる  
- 七夕賞はハンデ戦。人気薄も絡むが、**4角で前め〜中団にいないと厳しい**

## 過去傾向（台本で使える数字）

### 脚質（七夕賞／福島芝2000の一般傾向）
- 先行が中心。4角5番手以内が勝ち馬の大半  
- 差しも届くが「勝ち切れず3着」が多い年あり  
- **後方一気（4角10番手以降）はほぼ全滅クラス**  
- 「早めに動いて粘る持続力」＞「直線のキレ一発」

### 枠順（過去10年イメージ）
- 内〜中枠が相対的に安定、という語りが多い  
- **7枠は不振データが目立つ**（七夕ネタの「枠連7-7」はほぼ出ない、という定番ネタにも使える）  
- ただし年によってバラつき大。枠だけで切らない

### 人気・ハンデ
- 1人気は過信禁物ゾーンもあるが、上位人気軸＋穴押さえが基本  
- 58kg以上は苦戦データ（今年はサヴォーナ・カラマが該当）  
- 54〜56kgの中間ハンデが狙いやすい、という定番フレーズ

### 年齢
- 4〜5歳が中心  
- 7歳以上は複勝率が落ちやすい（バトルボーン・ショウナンマグマ等は年齢ディスカウント材料）

## 今年のメンバーから見える展開仮説

### 仮説A（本線）: 前が複数いて平均〜やや前傾 → 好位持続が得
- 逃げ候補: ショウナンマグマ／バトルボーン／アスクナイスショー  
- 先行意識: サヴォーナ／センツブラッド／オーロラエックス／ヤマニンブークリエ  
- → 序盤のポジション争いはそこそこ激しい  
- → **キレ勝負の差し一辺倒は不利**  
- → 得する馬: 好位で運べる持続型（サヴォーナ、センツブラッド、ヤマニン等）  
- → 損する馬: 後方待機の末脚型、スロー向きの切れ味型

### 仮説B: ショウナンマグマ単騎逃げでマイペース → 前残り
- 他が牽制して番手待機  
- → 前が残る／なだれ込み  
- → 得: 2〜4番手のサヴォーナ、バトルボーン、アスクナイスショー  
- → 損: メリオーレム、ボーンディスウェイ、オニャンコポンなど後方組

### 仮説C: 先行争い激化でハイ → 差し・まくり浮上
- 逃げ3頭＋先行勢が被る  
- → 3〜4角で前がばてる  
- → 得: デムーロのメリオーレム、マイネルモーント、オールナット  
- → 損: 逃げ負けたショウナンマグマ、被ったバトルボーン、58kgの前め人気馬

## ペース目安（語り用）
- 勝ち時計イメージ: 良馬場なら1:58〜2:00台  
- 上がり: 先行35秒前後／差し34秒台  
- 今年は開催3週目・Bコース2日目 → **内前が生きやすい可能性**（雨なら一変）

## 馬場・天候メモ
- 日曜は雨予報が出やすい時期。稍重以上なら差し寄りに修正  
- 良〜稍重の分岐は台本の「最後の注意」パートで触れると良い
