# 即読み用1枚（枠順待ち・仮）

VOOM収録前のカンペ。枠順後は赤字で上書き。

## レース
七夕賞 G3／7/12(日) 福島11R／芝2000／16頭／ハンデ

## 仮隊列（脚質ベース）
逃げ: ショウナンマグマ（±バトル／アスク）  
先行: サヴォーナ・センツ・オーロラ・ヤマニン  
中団: カラマ・コントラ・クリスマス  
差し後: オールナット・マイネル・メリオーレム・リカン・ボーン・オニャンコ

## 本線ペース
平均〜やや前傾（逃げ複数ならハイ／マグマ単騎ならやや緩い）

## 仮・得する馬
1. **アスクナイスショー** … 55kg・先行・田辺・穴妙味  
2. **センツブラッド** … 先行・季節適性・叩き2戦目  

## 仮・損する馬
1. **オニャンコポン** … テンに行けず位置取り悪化  
2. **メリオーレム** … 直線短・小回りで届きにくい（※ハイなら逆転）

## 人気馬の扱い（枠待ち）
- サヴォーナ: 好位取れれば得／外々＋スローなら損  
- カラマ: 縦長の4〜6番手が理想／団子キレ負けは損  
- バトル: 楽な番手なら得／逃げ争い被りは損  

## 15秒版（枠なしでも言える）
```
七夕賞は直線短いから後ろ一気はキツい。
逃げはマグマ、先行にサヴォーナとアスク。
得しそうなのは斤量軽いアスクとセンツ。
損しそうなのは位置取り悪いオニャンコと、届きにくい差しのメリオーレム。
枠出たら隊列確定版出す。
```
