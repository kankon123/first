# ローカルPC資料の取り込みメモ

## 現状（重要）

この作業は **Cursor Cloud Agent** 上で動いており、ユーザーPCのローカルディスクには直接アクセスできません。

確認済みで見つからなかったもの:
- ローカルの競馬／LINE VOOM／台本フォルダ
- 過去エージェント実行内のローカルパス参照
- このリポジトリ外のユーザー資料

そのため、いまの `tanabata-sho-2026/` は **Web公開情報ベースの下準備** です。  
ローカルの独自メモ・過去台本・脚質表・口調ルールがある場合は、下のいずれかの方法で共有してください。

## 共有方法（どれでも可）

1. **このリポジトリにコピー**  
   `tanabata-sho-2026/local-import/` にファイルを置いて再依頼
2. **チャットにパスを貼る**（ローカルAgent／Desktopで開いている場合）  
   例: `C:\Users\...\Documents\競馬\七夕賞\`  
   → そのパスを読める環境なら参照します
3. **主要ファイルをチャットに貼り付け／添付**  
   台本サンプル、得損の型、口調ルール、脚質表など

## 取り込みたいローカル資料の優先順位

| 優先 | 内容 | 反映先 |
|------|------|--------|
| 高 | 過去のLINE VOOM台本（得する馬／損する馬系） | `05` の口調・構成を合わせる |
| 高 | 自分用の脚質／隊列メモ | `01` `03` を上書き |
| 高 | 言い回し・禁止表現・締めの定型 | `05` に反映 |
| 中 | 七夕賞／福島の自作データ | `02` `04` に反映 |
| 中 | サムネ文言・テロップ型 | `05` に追記 |
| 低 | 他重賞の類似台本 | 構成参考 |

## 受領後にやること

- [ ] `local-import/` の内容を読む
- [ ] 口調・構成を既存テンプレに合わせて修正
- [ ] 仮の得損をローカル方針で差し替え
