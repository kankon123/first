# LINE VOOM 台本テンプレ（枠順穴埋め式）

想定尺: **45〜70秒**（読み上げ約350〜500字）  
トーン: テンポ速め・結論先出し・専門用語は短く

プレースホルダ:
- `【枠X】` `【馬番N】` … 枠順発表後に置換
- `【得1】` `【得2】` `【損1】` `【損2】` … 04の表から転記
- `【隊列一言】` … 03の確定隊列を1文に

---

## A案（本線）: 展開→隊列→得損

### 画面テキスト案（テロップ）
1. 七夕賞2026 展開予想
2. 隊列こうなる
3. 得する馬／損する馬
4. 結論

### 読み上げ台本

```
七夕賞、枠順そろったから展開いくよ。

福島芝2000は直線短い。後ろ一気は基本キツい。
今回の隊列は【隊列一言】。

ペースは【平均〜やや前傾／単騎逃げでやや緩い／ハイ】想定。

で、得する馬。
1頭目、【得1】。【理由15字】。
2頭目、【得2】。【理由15字】。

逆に損する馬。
【損1】は【理由15字】。
【損2】は【理由15字】。

まとめ。
前が残るなら【得側の先行名】。
流れれば【差し名】まで。
枠と隊列、ここまで見た人は ind で。
```

### 文字数目安
導入40字 → 隊列80字 → 得80字 → 損80字 → 締め60字 ≒ 340字
