# 枠順反映チェックリスト

枠順発表後、上から順にやる。所要イメージ: 資料更新→台本清書まで一気に。

## 1. 情報取得
- [ ] JRA／netkeibaで枠順・馬番を確認
- [ ] 騎手・斤量に変更がないか再確認
- [ ] 当日天候・馬場（良／稍重）の最新をメモ

## 2. `01_出走馬プロフィール.md`
- [ ] 枠・馬番列を追加（または別表でOK）
- [ ] 想定人気を直前オッズに軽く更新（任意）

## 3. `03_隊列仮想定.md`
- [ ] 枠順記入欄を埋める
- [ ] 逃げ争いの修正（内の逃げ候補がハナを取りやすいか）
- [ ] 「確定隊列」を1行で書く
- [ ] 4角通過イメージを枠込みで更新

## 4. `04_得する馬損する馬_枠順別シナリオ.md`
- [ ] 型①〜④のどれが本線か決める
- [ ] 得2・損2を表に記入（理由15字）
- [ ] 人気馬が外枠なら型③を優先検討

## 5. `05_LINEVOOM台本テンプレ.md`
- [ ] A/B/Cから採用案を選ぶ
- [ ] プレースホルダを全部置換
- [ ] 声に出して45〜70秒か確認
- [ ] サムネ文言を馬番入りに更新
- [ ] 「完成版メモ欄」に全文を保存

## 6. 品質チェック（投稿前）
- [ ] 馬名・枠番・馬番の食い違いなし
- [ ] 「絶対」「必ず」など言い切りすぎを避ける
- [ ] 自己責任の一文あり
- [ ] 得損の理由が「枠」か「脚質」か「ペース」か分かる

## 7. 発表後の即書き用メモ

```
発表時刻:
天候/馬場:
逃げ並び所見:
本線ペース:
得1 / 得2:
損1 / 損2:
台本採用: A/B/C
投稿URL:
```

## クイック判断フロー

```
逃げ候補が内枠に2頭以上いる？
  YES → 平均〜ハイ寄り。差しの得を1頭入れる
  NO  → 単騎or手薄。前残りの得を厚く

1人気が7〜8枠？
  YES → 損する馬に入れやすい（VOOM映え）
  NO  → 人気馬は互角〜得で、穴の得を強調

雨で稍重以上？
  YES → 差し寄りに得損を1段階スライド
  NO  → 内前本線のまま
```
