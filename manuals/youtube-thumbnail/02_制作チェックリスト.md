# サムネイル制作チェックリスト

動画公開前に、このリストで最終確認する。  
本編：`01_サムネイル設計マニュアル.md`

---

## A. 公開前クイックチェック（必須）

- [ ] スマホ実機で見たとき、文字が読める
- [ ] 解像度が **1280×720**（またはそれ以上）
- [ ] 1〜2秒で「何の動画か」「なぜ見るべきか」が伝わる
- [ ] 一番伝えたいキーワードが最大・最も目立つ
- [ ] 文字数が多すぎない（引き算できている）
- [ ] 背景と文字のコントラストが十分
- [ ] 動画内容と乖離していない（釣りになっていない）
- [ ] チャンネルの色・トーンと大きく外れていない

---

## B. 基本原則（①）

- [ ] 視線誘導（Z型：左上→右上→左下→右下）を意識した配置
- [ ] インパクト（色・文字サイズ・矢印／囲みなど）がある
- [ ] 関連性がある
- [ ] シンプルである
- [ ] ブランドとしての統一感がある

---

## C. カラー（②）

- [ ] 目立たせたい箇所が色で際立っている
- [ ] ブランドカラー（メイン／サブ／アクセント）を使っている
- [ ] 与えたい印象と色の心理効果が合っている
- [ ] 色配分がおおむね **70 : 25 : 5**
- [ ] 背景とのコントラストが取れている

---

## D. 文字（③）

- [ ] シンプルで読みやすいフォント（装飾過多でない）
- [ ] 主テキスト大／サブテキスト小の階層がある
- [ ] 文字色と背景のコントラストが高い
- [ ] 文字は短く、キーワードに絞っている
- [ ] 配置が視線の流れと合っている
- [ ] 画像と文字のバランスが取れている

---

## E. 画像（④）

- [ ] パッと見で目を引く
- [ ] （必要なら）感情に訴えかける表情・構図
- [ ] メッセージが明確（before/after等の変化がわかる）
- [ ] ターゲット層の世界観に合っている
- [ ] （可能なら）独自性がある
- [ ] 粗くない／意図的に荒い以外は高解像度

---

## F. コントラストとシンプルさ（⑤）

- [ ] 明暗・色彩のコントラストが高い
- [ ] 情報の詰め込みすぎがない
- [ ] 強調ポイントが1つに絞れている
- [ ] チャンネル特徴が伝わる
- [ ] スマホでもスケールして読める

---

## G. 違和感テクニック（⑥）

次のどれか（または複合）で「どういうこと？」を生めているか。

- [ ] 矛盾（〇〇なのに△△）
- [ ] ギャップ（期待とのズレ）
- [ ] 不自然（普通ならこうなのに）
- [ ] 数値の異常感（基準値とのズレ）
- [ ] 否定・禁止（食べてはいけない、など）

**セルフテスト：** 初見の人に見せて「何が気になる？」と聞いたとき、答えが返ってくるか。

---

## H. ワードチェック（⑧）

使っているワードが次のどれかに当てはまるか（必須ではないが強い）。

### 簡単・手軽さ
シンプル／たった／まずは／〇〇するだけで△△／初心者／初めて／入門／瞬時に／時短／一発

### 早わかり・網羅性
まとめ／総ざらい／〇〇版／〇〇選／〇〇パターン／ポイント／テク／裏ワザ／コツ／マニュアル

### 知識
メリット／共通点／理由・ワケ／特徴／方法／条件／基本／雑学／○○と△△の違い／なぜ○○なのか

---

## I. 競合との差分（⑦・任意だが推奨）

- [ ] 同ジャンルの伸びているサムネを2〜3本見比べた
- [ ] 共通の成功要因を取り入れている
- [ ] 差分（差別化）を1つ以上入れている
- [ ] （季節・トレンドがあるなら）織り込んだ
