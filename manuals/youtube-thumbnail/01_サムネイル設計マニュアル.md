# YouTubeサムネイル設計マニュアル（本編）

## はじめに

視聴者がチャンネルを選ぶ時代です。SNSプラットフォーム間のユーザー取り合いが激化し、発信者も増え、可処分時間の奪い合いになっています。

選択肢が多い中で自分のチャンネルを見てもらうには、**強烈な興味付け**が必要です。その手段のひとつが、サムネイルの質を上げることです。

### こんな悩みはありませんか？

- 再生回数が全然伸びない
- 動画が伸びるか伸びないかが完全に運ゲーになっている
- 単発ではヒットするが、継続して当て続けることができない

その原因はサムネイルにあるかもしれません。

---

## ①サムネイルの基本

何事も基本は重要です。日が経つにつれて基本がおろそかになっていないか、今一度立ち返りましょう。意識すべき点は次の3つです。

### 1. サムネイルの役割（5つ）

| # | 役割 | 説明 |
|---|------|------|
| 1 | 第一印象を決める | 視聴者が最初に見る接点 |
| 2 | 内容を簡潔に伝える | 動画の中身を一瞬で示す |
| 3 | 興味を引きクリック率を上げる | CTR向上の直接要因 |
| 4 | ブランディングと一貫性 | 統一表現で記憶に残す |
| 5 | 競合との差別化 | 目立つことで選ばれる |

視聴者はチャンネル名ではなく、サムネイルで記憶します。表現を統一すると良いのはこのためです。

### 2. チャンネル成長への影響（4つ）

| 影響 | 内容 |
|------|------|
| 第一印象 | クリックするかどうかを決める重要要素 |
| 視聴率向上 | CTRが上がり、視聴回数が増える |
| 登録者増加 | 質が高いと信頼性が高まり、登録につながる |
| ブランドイメージ向上 | プロフェッショナルな印象を作る |

一番の目的は「視聴を開始してもらうこと」ですが、ファン化やブランド形成の観点でもサムネイルは重要です。

### 3. クリック率向上の基本原則（5つ）

#### 視聴誘導

重要な情報や要素を強調し、視線を誘導する。視聴者は**Zの字**で見ます。

```
左上 → 右上
  ↘
左下 → 右下
```

この視点誘導を意識して配置する。

#### インパクト

鮮明な色・大きな文字で視認性を高め、注意を引く。赤丸・矢印などはわかりやすい例。

#### 関連性

動画内容との関連性が高く、期待に応えるサムネにする。釣りサムネにならないよう注意。

#### シンプルさ

情報過多にしない。何を盛り込むかを考え、引き算で設計する。

#### ブランディング

チャンネルの特徴・個性を表現し、統一感のあるサムネを作る。

> 「このチャンネルはこういうサムネイルだよな！」と思ってもらえることが重要。

## ②カラー選び

サムネイルの目的は視聴者を引き付けること。カラーはその影響力が大きい要素です。意識すべき点は5つ。

### ✅ 鮮やかな色を選ぶ

ジャンルによっては鮮やかさが正解とは限らないが、目を引く明るい色・コントラストの強い色で視認性を上げる。目立たせたい箇所をきちんと目立たせる色使いを考える。

視認性が低い＝見にくい＝クリックされない。

### ✅ ブランドカラーを活用

チャンネルのイメージカラーを意識する。伸びているチャンネルでは色が統一されている。

**例：2chスカッと系**

| パターン | メイン | サブ | アクセント① | アクセント② |
|----------|--------|------|--------------|--------------|
| A | 黄色 | 濃黄色 | 紫 | 赤 |
| B | グレー | 濃紺 | 黄色 | 赤 |

「このCHはこういうサムネ」とわかっていれば、ファンは迷わずクリックする。最初はうまくいっているCHを真似し、徐々に独自性を出す。

### ✅ 色の心理効果を理解

| 色 | 印象 |
|----|------|
| 緑 | 安らぎ、バランス、調和、自然 |
| 青 | 誠実さ、直感力 |
| 赤 | 情熱、エネルギー、生命力 |
| 黄色 | ユーモア、無邪気さ |

与えたいイメージに沿った色を選ぶ。青で愛情、黒で明るさ、水色で温かさは表現しにくい。

参考：[色彩心理（i-iro）](https://i-iro.com/psychology)

### ✅ 色の組み合わせ

センスではなくパターンで決める。

1. メインカラーを選ぶ
2. メインを引き立たせる色（補色など）を2色選ぶ
3. **70 : 25 : 5** でメインを際立たせる

### ✅ 背景色とのコントラスト

文字や画像が見やすくなるよう、背景とのコントラストを意識する。視認性を下げず、狙ったワードを目立たせる。

### カラー選びまとめ

- 鮮やかな色を選ぶ
- ブランドカラーを活用
- 色の心理効果を理解
- 色の組み合わせ（70:25:5）
- 背景色とのコントラスト

## ③文字の配置とフォント選び

文字は情報伝達と全体バランスの両面で、視認性を上げる重要要素。疎かだとチープで不恰好なサムネになる。意識すべき点は6つ。

### ✅ フォント選び

視認性の高いシンプルなフォントを選ぶ。装飾が少なく読みやすいものが望ましい。伸びているスカッと系はシンプルなゴシック体がほとんど。変な装飾は見づらく、伸びにくい。

### ✅ フォントサイズ

重要な情報は大きく、サブテキストは小さくし、視覚的な階層を作る。

**例（スカッと系）**

- 「再婚」
- 「突然震え出し」
- 「廊下な！」

動画の核となる要素を大きくする。

### ✅ 色のコントラスト

文字と背景のコントラストを高くする。背景が黄色なら文字も黄色はNG。補色（例：紫）で文字を際立たせる。

### ✅ 文字数の制限

クリック判断はだいたい**1〜2秒**。文字が多いと何を見ていいかわからない。文字は短くシンプルに。キーワードを絞る。

足し算ではなく**引き算**。一番伝えたいこと以外を引く。

### ✅ テキストの配置

視線は左上から右下へ斜めに流れる。その流れを意識して配置する。

### ✅ バランス

ジャンルで最適バランスは異なる。画像メイン／文字メイン／画像のみ、いずれもあり。身内の意見などで全体バランスを整える。

### 文字まわりまとめ

- フォント選び
- フォントサイズ
- 色のコントラスト
- 文字数の制限
- テキストの配置
- バランス

これらが総合され、「見やすいか／クリックするか」が決まる。

## ④画像の選定

クリック率の上がる画像は、一瞬で興味付けできている。パッと見で決まるため、インパクトが必要。意識すべき点は6つ。

### ✅ 視聴者の目を引く

鮮やかな色彩や驚きの要素で興味を喚起。画像単体で衝撃を与えられるものが良い。

**例：** ダイエット系で筋肉質だった足 → K-popアイドル級の美脚の対比。

### ✅ 感情に訴えかける

笑顔や驚きの表情などで感情移入させる。

**例：** 「絶対に笑ってはいけない」なら、笑いを堪えて顔を真っ赤にしているイラスト。

必須ではないが、視点として持つとバリエーションが広がる。

### ✅ 明確なメッセージ

画像が伝える内容・チャンネルテーマが明確か確認する。before/afterなら、より酷い状態 → より最高な状態の変化をはっきり見せる。

### ✅ ターゲット視聴者に合わせる

年齢層・興味に合わせた画像を選ぶ。

**例（貧乏系訴求）：** お洒落な食事ではなく、海苔・納豆・ご飯のみの朝食、日の丸弁当、薄暗く古びた部屋など。

### ✅ 独自性を出す

他CHと差別化できるスタイルや要素を取り入れる。最初は難しく、需要を外すこともあるので、徐々にできるようになれば十分。

### ✅ 高品質な画像

粗くない、ピクセル化されていない高解像度を使う（ジャンルによってはあえて荒い画像もあり）。

**推奨解像度：1280 × 720**（YouTubeヘルプ準拠）

### 画像選定まとめ

- 視聴者の目を引く
- 感情に訴えかける
- 明確なメッセージ
- ターゲットに合わせる
- 独自性を出す
- 高品質な画像

ウケているサムネにはパターンがある。再現できるよう言語化していく。

## ⑤コントラストとシンプルさ

パッと見で意図が理解できる必要がある。強調したい部分を明確に、シンプルに伝える。意識すべき点は5つ。

### ✅ コントラストを高める

明暗・色彩のコントラストで視認性を上げる。背景を暗くして白い文字を載せるだけでもメッセージが明確になる。背景と同色の文字はNG。補色に近い色でコントラストを上げる。

### ✅ シンプルなデザイン

情報を詰め込みすぎない。新聞のように文字でビッシリ埋まっているものは避け、パッと見で理解できるようにする。

### ✅ 強調したいポイントの明確化

動画の一番の強み・テーマを簡潔に表す。

| ジャンル | 例 |
|----------|-----|
| ダイエット | 「-7キロ食事法」「ウエスト-15cm簡単トレーニング」 |
| 恋愛 | 「レスについて」「どう復縁した？」 |

### ✅ チャンネルの特徴を反映

一目でチャンネル内容・個性がわかるようにする。ファンに伝わる特徴があれば、迷わずクリックされる。共通言語を入れるのもファン化につながる。初期から難しくても、徐々に独自性を出す。

### ✅ スケーラビリティ

視聴の大半はスマホ。スマホ表示でも要素がはっきり見えるようにする。

**確認方法の例**

- サムネをスマホに送って実機確認
- 予約投稿時点でスマホのアナリティクスから確認

テキストが小さいと本当に見にくくなるので注意。

### コントラスト・シンプルさまとめ

- コントラストを高める
- シンプルなデザイン
- 強調ポイントの明確化
- チャンネル特徴の反映
- スケーラビリティ（スマホ確認）

「チャンネル特徴の反映」以外は最初から意識できる基本。疎かだと伸ばしにくい。

## ⑥クリック率を増やすテクニック（違和感）

いちばん大切なテクニックは **「違和感」**。

### 違和感とは

期待や慣れ親しんだ基準と異なり、「なんか違う」「どういうこと？」「普通だったらこうなのに」と感じさせること。

言い換えると：**矛盾・ギャップ・不自然**。

違和感でツァイガルニク効果や認知的不協和が働き、目に止まりやすくなる。伸びているサムネで高頻度に使われている。

### 具体例

| # | サムネ例 | 違和感ポイント |
|---|----------|----------------|
| 1 | ドリームハウス。やばい家5選 | ドリームなのにやばい？普通の家に何がドリーム？ ※「素敵な家5選」だと普通すぎて見られない |
| 2 | （著名人に似た女性）路上インタビューに答えたこの女性の正体がやばい | もしかしてあの人？なにがやばい？インタビューに答えていたの？ |
| 3 | 無能と言われている俺が休んだら、トラブルが増えた | 無能が休んでも影響ないはずでは？トラブルは減るのでは？ |
| 4 | 大谷もすごかったけど、この若い投手、想像をはるかに超えた | 大谷よりすごい人がいた？大谷が一番では？ ※他の日本人だと違和感が弱い |
| 5 | ロシア軍最強戦車が破壊 | 最強なのに破壊？最強戦車とは？どうやって？ |
| 6 | 数年でゴミになる！ハイブリッド購入者の末路 | 車は10年以上乗れるのでは？ハイブリッドは伸びるはずでは？ |
| 7 | アジア初の柱無しスタジアム | 柱無しでどう立っている？現実的にできる？ |
| 8 | 毎日納豆を1パック食べ続けた末路とは | 健康なイメージなのに末路？ ※コーラだと「悪そう」が当然で伸びにくい |
| 9 | 96%が2分で爆睡できる方法 | すごすぎる／どういうこと？ ※数値で基準値とのズレを作る |
| 10 | （バナナ）これだけは絶対に食べるな。早死に確定 | 日常で食べているのに危険？否定されると余計に気になる |

違和感で潜在意識に働きかけると、思わずクリックしてしまう。最初は成功例の真似から入り、作り方を覚える。

## ⑦競合の分析方法

成功には先人の知恵が必須。競合の「なぜ伸びているか」「なぜおすすめに出るか」を分析する。1から作ると時間がかかり、質も上げにくい。意識すべき点は8つ。

### ✅ 競合チャンネルの特長把握

ジャンル・ターゲット・訴求の仕方を把握する。カラー／文字／画像／引き付け方／違和感の出し方を分析する。

### ✅ サムネイルの共通点と相違点

デザイン・色・画像などを比較。**共通点と相違点をセット**で把握する。

- A・B両方にある要素 → 成功要因として捉える
- 片方にしかない要素 → 特に気にしなくてよい場合が多い

### ✅ クリック率の高いサムネの要因

成功例からデザイン・インパクトを学び、ヒット要素を取り入れる。

**再ヒットの例**

| | 内容 |
|--|------|
| 先出し | 泥ママがロッカーに隠れている最中に引っ越し業者が運び出した |
| 後出し | 泥ママが床下収納に隠れている最中に米袋を置かれて閉じ込めた |

両方10万再生超。ヒット要素（まぬけ感・簡単に出てこれない感）を変えず、シーンだけ変えた。

### ✅ 差別化要素の発見

手順：

1. 競合CHの伸びているネタを見つける
2. YouTube検索窓で同様のネタを調べる
3. 差分を観察する

伸びているサムネの差別化パターンが見えてくる。

### ✅ 視聴者の意見を取り入れる

競合のコメント欄を参考にする。コミュニティ機能でA/Bテストやフィードバックも有効。

### ✅ ターゲット視聴者の理解

関心・ニーズに合わせたデザインにする。関連CHの伸びているチャンネルを10個ほど分析し、伸びているサムネを表にまとめるとよい。

### ✅ トレンドや季節性を活用

クリスマス・バレンタイン・ハロウィン・オリンピックなど、時期に合わせると「今の自分に関係している」と思われやすい。どんな要素がクリックを促したかを分析しておく。

### ✅ 視聴者の行動データ分析

クリック元（おすすめ／関連）を確認。関連からの場合は関連先も見る。自CH視聴者が他にどんなCHを見ているか把握すると、興味の手がかりになる。

### 競合分析まとめ

- 特長把握
- 共通点と相違点
- CTR高いサムネの要因
- 差別化要素の発見
- 視聴者意見の取り込み
- ターゲット理解
- トレンド・季節性
- 行動データ分析

分析結果を自CHに取り入れると、1からより早く・質の良いサムネが作れる。

## ⑧バズりワードの具体例

## ⑨ストックの溜め方

ストックでヒット要素の共通項を知り、自CHに活かす。

### 記録項目（スプレッドシート推奨）

1行＝1動画で次を記録する。

| 列 | 内容 |
|----|------|
| チャンネル名 | 競合CH名 |
| タイトル名 | 動画タイトル |
| サムネイル画像 | スクショ or リンク |
| URL | 動画URL |
| 切り口 | 訴求の仕方 |
| ヒット要素 | なぜ伸びたか（具体的に） |

### 具体例

#### 例①（伸びた）

| 項目 | 内容 |
|------|------|
| サムネ | 毎日納豆を1パック食べ続けたらどうなるのか！？ |
| 切り口 | 毎日食べるとどうなるのか！？ |
| ヒット要素 | 体に良さそうなものを食べすぎるとどうなるか？ → 知的好奇心 |

#### 例②（伸びなかった＝反面教師）

| 項目 | 内容 |
|------|------|
| サムネ | 毎日カップラーメンを食べ続けたらどうなるのか！？ |
| 切り口 | 毎日食べるとどうなるのか！？ |
| 狙った要素 | 体に悪そうなものを食べすぎるとどうなるか？ |
| なぜ弱い | カップラーメンは最初から悪そう → 「どうせ不健康になるだけ」で興味が薄い |

#### 例③

| 項目 | 内容 |
|------|------|
| サムネ | 絶対食うな！あの野菜を食うと体が毒だらけに |
| 切り口 | 絶対食うな |
| ヒット要素 | 野菜＝体に良いイメージなのに毒だらけ？ |

#### 例④

| 項目 | 内容 |
|------|------|
| サムネ | 食べ続けるとがんになる食べ物 |
| 切り口 | 食べ続けるとどうなるか／危険な食べ物 |
| ヒット要素 | 何を食べるとがんになる？今後のために知りたい |

#### 例⑤

| 項目 | 内容 |
|------|------|
| サムネ | バナナを日本で食べ続けるとどうなるのか |
| 切り口 | 食べ続けるとどうなるのか |
| ヒット要素 | 普段食べているものなのに？／数値を入れる（2本） |

### 注意：抽象度を上げすぎない

「ヒット要素が同じものばかりになる」のは、抽象度が高すぎるサイン。

```
人 → 哺乳類 → 生物
（具体）　　　　（抽象）
```

「生物」まで抽象化せず、できるだけ「人」レベルまで具体化する。最初は難しくても継続が力。ストックが多いほど、短時間で高品質なサムネが作れる。

## 最後に

クリック率の上がるサムネイルのために検討する内容は次の9点。

1. サムネイルの基本
2. カラー選び
3. 文字の配置とフォント選び
4. 画像の選定
5. コントラストとシンプルさ
6. クリック率を増やすテクニック（違和感）
7. 競合の分析方法
8. バズりワードの具体例
9. ストックの溜め方

知識は使いこなせなければ意味がない。日頃からリサーチと分析を繰り返し、冒頭離脱を減らし、パフォーマンスの高い動画作りに役立ててください。
