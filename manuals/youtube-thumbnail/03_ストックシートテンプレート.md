# サムネイル・ヒット要素ストックシート テンプレート

スプレッドシートにコピーして使う想定のテンプレートです。  
本編：`01_サムネイル設計マニュアル.md` の「⑨ストックの溜め方」対応。

---

## 記録ルール

1. **1行＝1動画**
2. 伸びた動画だけでなく、**伸びなかった動画も記録**する（反面教師）
3. 「ヒット要素」は抽象化しすぎない（「生物」ではなく「人」レベルまで具体化）
4. 週に数本でもよいので継続する

---

## 列定義

| 列名 | 必須 | 記入例・説明 |
|------|------|--------------|
| 日付 | ○ | 記録した日（YYYY-MM-DD） |
| 結果 | ○ | 伸びた / 普通 / 伸びなかった |
| チャンネル名 | ○ | 競合または自CH名 |
| タイトル | ○ | 動画タイトル |
| サムネ文言 | ○ | サムネに書いてある文字をそのまま |
| サムネ画像 | △ | スクショURL or ファイル名 |
| URL | ○ | 動画URL |
| 再生数（目安） | △ | 記録時点の再生数 |
| 切り口 | ○ | 訴求の仕方（例：毎日食べるとどうなる） |
| ヒット要素 | ○ | なぜ伸びたか／狙った違和感を具体的に |
| 違和感タイプ | △ | 矛盾 / ギャップ / 数値 / 禁止 / その他 |
| バズワード | △ | 使われている強いワード |
| カラー傾向 | △ | 例：黄メイン＋紫アクセント |
| メモ | △ | 自CHへの転用アイデア |

## 抽象度チェック（記入前に見る）

ヒット要素が次のようになっていないか確認する。

| NG（抽象すぎ） | OK（具体） |
|----------------|------------|
| 好奇心を刺激している | 体に良さそうな納豆を食べ続けるとどうなるか気になる |
| ギャップがある | ドリームハウスなのに「やばい」と言っている矛盾 |
| 数字が入っている | 96%・2分など、常識の基準値とズレた数字 |

抽象 → 具体に直してから記録する。
