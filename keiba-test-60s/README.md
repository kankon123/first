# 競馬動画テスト（札幌記念2026・約60秒）

## 相談で確定した仕様（本テスト）

| 項目 | 決定 | 理由 |
|------|------|------|
| 種別 | **レース予想**（得する馬／損する馬） | LINE VOOM向けの既存台本型。パイプライン検証に最適 |
| 尺 | **約53秒**（目標55〜60） | 初回は短尺で音声・字幕・モバイル再生を確認。8〜10分は次段 |
| 声 | **Keita**（`ja-JP-KeitaNeural`） | 解説トーン。天気テストと同系統で比較しやすい |
| 画角 | **1280×720** | モバイル確認済みの安定設定 |
| 音声 | **AAC 44.1kHz ステレオ** + `faststart` | チャット内再生の安定寄り |
| 字幕 | **ASS焼き込み** | モバイルでも字幕が落ちない |
| 映像 | 静止画4枚 + 軽いズーム | 画像生成＋ffmpegの既存能力内 |

### あえて今回やらなかったこと

- 8〜10分尺（画像80枚超・台本長文化）→ 短尺OK後に拡大
- Nanami → シリーズ声の本採用は視聴確認後に決める
- 実写レース映像・ユーザー本人声・権利物ロゴ
