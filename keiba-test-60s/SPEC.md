# 尺・声・フォーマット相談メモ

日付: 2026-08-12  
目的: 競馬動画の**初回テスト1本**の仕様を決める

## 選択肢と推奨

### 1. 種別

| 案 | 向く用途 | 初回向き |
|----|----------|----------|
| A. レース予想（得損） | VOOM / Shorts | **推奨** |
| B. 結果まとめ | 日曜夜の速報 | 結果待ち |
| C. 出走馬紹介 | 枠順前の予告 | 尺が伸びやすい |

→ **A** を採用（既存の七夕賞台本型と接続できる）

### 2. 尺

| 案 | 字数目安 | 用途 |
|----|----------|------|
| **55〜60秒（採用）** | 320〜380字 | パイプライン検証 |
| 45〜70秒 | 350〜500字 | VOOM本番想定 |
| 8〜10分 | 2400〜3500字 | 本編 YouTube（次段） |

長尺希望は前回会話である。ただし**最初の1本は短尺でコーデック／字幕／声質を確認**する方が安全。

### 3. 声

| 声 | 特徴 | 判定 |
|----|------|------|
| **Keita（採用）** | 男性・落ち着いた解説 | 競馬解説に合いやすい |
| Nanami | 女性・明るい | 自己紹介デモで使用済。比較用に残す |

シリーズ固定は視聴後に決める。今回は Keita。

### 4. フォーマット（固定）

```
1280x720
H.264 Main @ level 3.1, yuv420p, CRF ~22
AAC LC 160k, 44100 Hz, stereo
-movflags +faststart
ASS 字幕焼き込み
```

### 5. 次回の分岐

- 短尺OK → 同じ型で枠順反映版、または Nanami 比較版
- 長尺へ → 3〜5分中間テスト → 8〜10分
