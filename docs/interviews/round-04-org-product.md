# Round 4 — 商品関係と組織（インタビュー記録）

**日付:** 2026-07-17  
**入力元:** 事業構想の整理（ユーザー提示）  
**ステータス:** Phase 1 設計仮説として確定

## Q1. 商品と研究の関係は？

研究が先。商品は研究成果のパッケージ。

```
研究サイクル → 公開（YouTube/note/LINE） → 有用な知見の抽出 → 商品化
```

最初から「人のために売る」が目的ではない。自分の仮説検証の成果が、結果として他者に役立つ形で商品になる。

## Q2. 媒体と役割の対応は？

| 媒体 | 役割 |
|---|---|
| YouTube | 研究発表（広く仮説と検証過程を見せる） |
| note | 研究レポート（深い論理・再現手順） |
| LINE | 速報（タイミングが価値になる情報） |
| 商品 | 研究成果（体系化された手法・ツール・教材） |

## Q3. 現在の組織は？

創業者一人。経営・戦略・制作・研究を兼務。  
運用上限は長期資産2 + 実験1 程度。

## Q4. 将来の組織像は？

創業者は経営・戦略に集中。各専門ブランドに担当者（専門家・仲間）を置く。

例:

- AIデータ担当
- 血統担当
- トラックバイアス担当
- パドック担当
- 馬券戦略担当

最終的に 10〜20 ブランドがあってもよい。ただしブランド追加は「担当可能性」と「検証済みの勝ち筋」が条件。
