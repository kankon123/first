# Round 1 — 理念の核（インタビュー記録）

**日付:** 2026-07-17  
**入力元:** 事業構想の整理（ユーザー提示）  
**ステータス:** Phase 1 設計仮説として確定

## Q1. 何を証明したいのか？

競馬を「投資的な手法」として、再現性を持って勝てるものにできるかを証明したい。

情報発信そのものが最終目的ではない。研究を継続するための事業として発信がある。

## Q2. なぜ「チャンネル」ではなく「研究所」なのか？

研究所として次のサイクルを回し続けるため。

1. データを集める  
2. 仮説を立てる  
3. 検証する  
4. 公開する  
5. 改善する  

YouTube は研究発表の場。note は研究レポート。LINE は速報。商品は研究成果。

## Q3. やらないこと（境界）

- 属人的な顔出し発信を前提にしない（ブランドに思想を持たせる）
- YouTube ポリシーを破る実験をしない
- 単一チャンネル依存の事業構造にしない
- 「人のため」を最初からの綺麗事として掲げない（まず自分の仮説検証。成果が他者に役立つことは結果として望ましい）

## Q4. 現時点の本音（経営前提）

生活が成り立たなければ理想も研究も続かない。  
YouTube / note / LINE / 商品販売などで収益を作りながら進むことが前提。
