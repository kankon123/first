## 商品追加時のチェックリスト

新しい商品を追加する際:

- [ ] `products.json` に商品マスターを追加
- [ ] `fitTags` を設定（悩みタグと対応）
- [ ] `suitableFor` / `notSuitableFor` を明記
- [ ] 対応する棚(Sxx)を更新
- [ ] 該当する `results.json` の推奨リストに追加
- [ ] 診断ロジック（domain/）は変更不要であることを確認
- [ ] `lastVerifiedAt` を記録
