# 01 — 理念（Philosophy）

**参照インタビュー:** [interviews/round-01-philosophy.md](interviews/round-01-philosophy.md)

## 1. 使命（Mission）

競馬を「運任せの娯楽」ではなく、**投資的な手法として再現可能か**を検証し、証明する。

## 2. 動機（Why）

本音の動機は研究にある。

- 本当に勝てる馬券術が完成するなら、情報発信は必須ではない  
- それでも発信するのは、研究を継続するための事業だから  
- 「人のため」から始める綺麗事ではない。まず自分の仮説を検証する  
- その成果が他者にも役立つなら、商品・コンテンツとして提供する  

## 3. 研究所としての定義

競馬研究所は、次のサイクルを回す組織である。

1. **データを集める**  
2. **仮説を立てる**  
3. **検証する**  
4. **公開する**  
5. **改善する**  

「予想を当てるチャンネル」ではなく、「検証過程を公開する研究所」として振る舞う。

## 4. 発信スタンス

### 理想の強さ

考えを堂々と発信する（主張をぼかさない）。

### 属人化しない

顔出し・個人カリスマに依存しない。  
**ブランドそのものに思想を持たせる。**

ブランドが持つべきもの:

- 主張（何を正しいと考えるか）
- 方法（どう検証するか）
- 言葉遣い（どう語るか）
- 禁止事項（何を言わないか）

## 5. 経営前提（現実）

理想だけでは続かない。

- 生活が成り立たなければ研究は止まる  
- YouTube / note / LINE / 商品で収益を作りながら進む  
- 収益は目的ではなく、研究継続の燃料  

## 6. やること / やらないこと

### やること

- データに基づく仮説検証と公開  
- 専門性を分けたブランド設計  
- 実験による学習速度の向上  
- ポリシーを守ったうえで複数収益源を持つ  
- 研究成果の体系化（将来の商品）  

### やらないこと

- ポリシー違反の煽り・断定表現による短期最大化  
- 単一チャンネルへの依存  
- 顔出し属人ブランドへの全賭け  
- 未検証の手法を「完成形」として売る  
- 専門性のない寄せ集めチャンネル化  

## 7. 判断に迷ったときの問い

1. それは研究か、単なるコンテンツ消費か？  
2. 再現可能な仮説になっているか？  
3. ブランドの思想と矛盾しないか？  
4. ポリシーリスクはないか？  
5. 一人運営の上限を超えないか？  
6. 将来の商品・組織に資産として残るか？  

## 8. 方針として確定したこと

| 項目 | 方針 |
|---|---|
| コア概念 | 競馬チャンネルではなく競馬研究所 |
| 証明対象 | 投資的・再現可能な馬券手法の可否 |
| 発信形態 | ブランド思想型（非顔出し前提） |
| 媒体役割 | YouTube発表 / noteレポート / LINE速報 / 商品成果 |
| 制約 | 全ブランドでポリシー順守 |
